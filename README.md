# 盗音（daoyin）

多平台音乐搜索、试听与高质量下载工具（洛雪音源兼容），面向飞牛 fnOS 打造纯原生应用版本。

## 功能

### 搜索、试听与下载

- 服务端内置 wy / kw / kg / tx 四平台搜索适配器，洛雪音源脚本用于取直链
- 试听自动最高可用音质（自动降级保证可播），带取链缓存
- 音质手动选择固定档位（flac24bit / flac / 320k / 192k / 128k），默认 flac24bit
- 智能下载队列：多源轮询、失败自动换源重试、无损音质实格式校验（音源返回 MP3 等非 FLAC 时自动换源）、试听片段防护、扩展名魔数纠正
- 跨平台兜底：本平台取链失败时自动搜索其他平台匹配换源

### 排行榜

- wy / tx / kg 三平台榜单浏览（数据缓存 10 分钟，支持手动刷新）
- 榜单歌曲直接入队下载

### 歌单下载

- 链接导入：wy / tx / kg 歌单解析 + 精准匹配确认，跨平台搜索匹配（原平台无命中时自动在其余平台搜索）
- 歌手硬性匹配门槛：无任何歌手交集即否决，支持多歌手拆分，杜绝翻唱/合唱版本误下载
- 歌单广场：wy / tx / kg / mg 四平台推荐歌单浏览（最热 / 最新排序、分页加载），歌单详情与歌曲直接入队
- 一键解析下载（解析 + 匹配 + 入队一步完成）；音质 / 歌词开关 / 歌词写入方式默认预选设置值

### 下载队列

- 实时进度（SSE 实时刷新），状态筛选（全部 / 下载中 / 待确认 / 失败 / 完成 / 已取消 / 已存在 / 文件缺失）
- 批量管理：批量取消 / 重试 / 换源 / 换音质 / 删除（可选同时清理本地文件）/ 强制重新下载
- 下载并发可调（1~20）、任务间隔可调、失败自动重试次数可调

### 本地文件管理

- **下载统计**：按磁盘真实文件数统计（记录按 `file_path` 去重且文件存在才计数），消除「软件已下载数」与「实际文件数」不一致
- **文件对账**：扫描下载目录与记录双向对比，列出「匹配 / 缺失 / 疑似改名 / 孤儿文件 / 共享文件」五类差异
- 支持一键重新关联改名文件、删除孤儿文件、清理共享重复记录（「下载完成」优先保留）
- **自愈**：启动与每 10 分钟自动校验已完成/已存在记录对应文件是否仍在，文件丢失时顶部提示并可一键清理

### 下载前预检与音乐多版本

- 搜索 / 排行榜 / 歌单广场列表直接标注「已下载」，已存在歌曲不再重复入队；批量入队自动跳过已存在并提示数量
- 多版本区分：同名同歌手 → 已下载；同名不同歌手 → 多版本；无 → 正常下载
- 多版本弹窗列出本地已有版本（文件名 + 大小），可选择「仍下载此版本 / 跳过 / 待会再说」
- 待确认持久化：多版本弹窗无人处理（关闭窗口 / 待会再说）时，歌曲保留在下载列表「待确认」区，可随时确认下载或跳过

### 歌词与元数据

- 下载后 ffmpeg 写入元数据（封面压缩内嵌、标签、内嵌歌词，缺失时降级跳过）
- 歌词双语（QQ QRC 解密、酷狗 KRC、咪咕 lrc/trc）；歌词可选外挂 `.lrc` 或内嵌到音频

### 音源管理

- 新增 URL / 上传 `.js` / 从文件夹批量上传 / 批量文本导入 / 完整包导入
- 检测、一键停用失效、清理失效、手动排序（拖拽 + 上移/下移/置顶）
- 音源同名冲突处理（覆盖 / 跳过）；连续失败自动熔断

### 飞牛 fnOS 集成

- 统一网关 `/app/daoyin` 访问，无对外端口
- 开放 API `trim.file.sharedAccess`：设置页应用内一键授权下载目录
- 口令鉴权（`AUTH_TOKEN` 空 = 开放模式），会话 7 天

## 开发

要求 Node ≥ 22、pnpm。

```bash
pnpm install
cp .env.example .env
pnpm dev          # http://localhost:18980
pnpm test         # vitest
pnpm typecheck    # nuxt typecheck
pnpm lint         # eslint
```

## 构建与打包

```bash
pnpm build                              # Nuxt 4 / Nitro node-server
pnpm build:fpk                          # 打 FPK 胖包（需 fnpack）
MIYIN_VERSION=3.0.0 REQUIRE_FNPACK=1 ./packaging/fnos/scripts/build-fpk.sh
```

Windows 下打 FPK（Git Bash + fnpack）：

```powershell
powershell -ExecutionPolicy Bypass -File scripts/setup-fnpack.ps1   # 下载 fnpack 到 tools/
MIYIN_VERSION=3.0.0 REQUIRE_FNPACK=1 FNPACK_OUT_DIR="D:\输出目录" bash packaging/fnos/scripts/build-fpk.sh
```

> 注意：飞牛网关模式下构建必须带 `NUXT_APP_BASE_URL=/app/daoyin/`（`build-fpk.sh` 已处理并禁用 MSYS 路径转换），否则应用 baseURL 损坏导致界面打不开。

详见 [`packaging/fnos/README.md`](packaging/fnos/README.md)。

## 安全

- 音源脚本在 `node:vm` 沙箱内执行：限制 `require` 白名单、定时器数量上限、初始化/取链超时、加载前扫描逃逸 payload 并拒绝
- SSRF 防护：服务端抓取用户可控 URL 前做内网地址校验 + `safeFetch`（IP 直连 + 原域名 SNI/Host，逐跳重新校验）防 DNS rebinding
- 会话口令鉴权；下载目录写入前探测可写性；ffmpeg 元数据值去除控制字符防注入
- 公网部署建议设置访问口令

## 合规

- 仅提供工具能力，不内置、不存储任何受版权保护的音频、歌词、封面内容
- 搜索走平台公开接口，直链获取由用户自行导入的音源脚本承担

本项目借鉴了同类音乐产品的设计思路。
